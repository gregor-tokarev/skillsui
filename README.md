Search and preview skills, install them for a project or your whole machine, and manage them
side by side with the keyboard.

https://github.com/user-attachments/assets/b722c953-6aff-44b6-84d8-db5f803e4e73

## Install

Available for macOS and Linux (glibc), on ARM64 and x64.

```sh
curl -fsSL https://raw.githubusercontent.com/gregor-tokarev/skillsui/main/install.sh | sh
```

Run `skillsui` from your project directory. Update with `skillsui update`.
